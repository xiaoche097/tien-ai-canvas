# 使用电商设计室

从境彻创意中心进入“电商设计室”，沿用当前境彻账号。退出或切换账号时，请回到境彻完成操作；不同账号的电商设计室项目和素材互相隔离。

## 开始一个商品项目

在“快速开始”填写商品信息或上传商品图，提交后进入商品分析。确认分析结果，再规划详情页模块；可以逐段修改文案和图片提示词，随后生成、重做和导出。项目也可以从“高级创建”建立，在“历史记录”继续编辑。

## 模型与费用

电商设计室使用境彻中当前可用的文本、看图、图片和配音模型。模型及账户额度在境彻“设置”中管理；生成请求经境彻服务端鉴权和计费。未配置相应能力时，操作会明确报错。

## 其他工具

“批量主图”用同一商品信息生成多张主图；“模特库”管理模特并进行试穿图生成；“套版中心”保存可复用的版式。

“视频生成”先根据商品图和卖点生成分镜，再生成每个镜头的图片并合成视频。合成调用境彻时间线任务，可选择配音、上传自定义背景音乐及转场。视频完成后可下载，历史视频只对当前账号可见。配音需要境彻配置兼容所选声音的 OpenAI Audio 模型。
