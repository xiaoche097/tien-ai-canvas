# Phase 2 来源对接：真实商品只读，精修结果隔离保存

后续进度：商品工作台内的精修、模块预览更新与导出中心下载已在独立 3003 数据快照接入，待真实浏览器验收。见 `docs/content/docs/progress/psd-phase2-integration.mdx`。下文记录原 3002 只读来源实验，仍保留其隔离行为。

## 本次交付

3002 实验页新增「从商品模块载入」：读取当前登录账号的真实商品，选择已有图像的模块，将模块当前图片送入 Photopea，并将实际商品、模块、源素材及源生成版本关联到隔离精修会话和后续版本。

本次是 Phase 2 的来源对接子任务，不代表完整 Phase 2 已完成。正式电商导航、工作台图片操作、当前预览、版本激活和导出中心均未修改；所有写入仍位于独立验收数据目录。

## 真实数据路径

1. 本地中间件验证境彻 session，然后携带该请求原有 Cookie，通过固定的回环服务读取 `/motu/api/projects` 和 `/motu/api/projects/:id`。
2. 列表响应只向浏览器暴露商品 ID/名称、模块 ID/名称、当前图像 ID 与实际匹配的源版本 ID，不转发完整项目、模型配置或任务正文。
3. 导入时重新读取商品详情，校验模块属于商品、当前图像仍是选择时的图像、素材属于当前商品及模块。
4. 仅构造 `/motu/api/files/...` 的已授权文件路径。不使用业务响应里的任意 public URL，不把 Cookie、Token 放进文件 URL 或 iframe 配置，不跟随跳转到其他服务。
5. 源图最多 50 MB，商品 JSON 最多 16 MB，读取有超时及流式大小限制。当前接受真实 PSD/PNG/JPG；其他格式明确报错，不声称已经支持。
6. 源文件复制到隔离会话，校验后从受保护的本地 source 接口发送给 Photopea。正式商品只有读取请求，没有素材上传、项目更新或版本激活请求。

源图片没有生成版本记录时，sourceVersionId 明确为 null；不拿任务 ID、其他图像的 active 版本或临时 UUID 冒充源版本。

## 最小数据增量

不新增表，也不迁移正式数据库。`PsdSession.origin` 和 `PsdVersion.origin` 记录：

- `projectId`、`moduleId`：正式商品与模块的真实 ID。
- `sourceAssetId`：加载时模块实际绑定的素材 ID。
- `sourceVersionId`：指向同一素材的真实生成版本，可为空。
- `projectName`、`moduleName`：加载时的名称快照。

会话的 ProductAsset.metadata.origin 及版本的 SectionVersion.promptSnapshot.psd.origin 保存这些字段。它们与隔离夹具自身的 projectId / sectionId 分开：正式 ID 仅用于来源追踪，不将测试记录伪装成正式商品外键。后续正式接入时需改为在已授权的真实业务 scope 中保存，并完成预览指针事务。

来源只由服务端从当前登录用户的电商响应构造；不接受浏览器直接提交任意 origin 对象或图片 URL。恢复 PSD 后再保存，仍从原会话继承来源；相同来源请求标识不能被复用于不同商品、模块、素材或源版本。

## 新增实验接口

| 路径 | 能力 |
| --- | --- |
| `GET /api/psd-lab/projects` | 当前账号可读取的真实商品列表 |
| `GET /api/psd-lab/projects/:id/modules` | 模块、当前图片与匹配源版本 |
| `POST /api/psd-lab/projects/:id/modules/:moduleId/import` | 同源表单提交 expectedAssetId 和请求 UUID；重新校验并创建隔离来源会话 |
| `GET /api/psd-lab/sessions/:id/source` | 校验会话所有权、路径及 SHA-256 后返回源文件 |

JSON 使用现有 http 信封，二进制用 http.raw。现有主产品路由没有注册这些接口。

## 已验证与边界

- 35 项专项测试、158 次断言通过；独立类型检查和构建通过。构建仍有既有的 logo.svg 运行时解析和大分块提示。
- 隔离版本列表新增 PSD/PNG 直接下载，复用已有鉴权及 SHA-256 校验文件接口；无需打开编辑器文档，保留当前编辑内容。文件名包含版本号及版本 ID 后缀；下载后进入本页下载记录。请求绑定账号取消边界，切换账号后的迟到结果不生成下载。JPG 仍需打开版本后通过编辑器导出，没有持久化 JPG 或新增正式导出中心入口。
- 下载专项覆盖版本/格式选择、二进制读取、取消信号传递与错误传播。实际浏览器下载与文件重开仍待验收。
- 新增「打开导入时原文件」：复用受保护 source 接口，读取会话导入时保留的原件，打开前提示保存未保存修改；保留精修历史，清除当前父版本和待重试快照。再次保存以原件为起点新增版本，正式预览不改变。服务层覆盖恢复原件后新增版本、原件及其他版本文件不变；页面交互待验收。
- 载入商品模块前读取当前账号隔离会话，仅匹配商品、模块与当前来源素材；跳过无保存版本的会话。找到后提示继续编辑已有 PSD 或基于模块当前图像新建，取消不打开文件。继续编辑同步该会话版本列表，新建仍走服务端当前图像复核。查找失败保留错误，不静默绕过为新建。
- 新增三项回归覆盖精确来源匹配、跳过未保存会话、无匹配来源及读取失败，并检查请求传递取消信号。复用会话的弹窗和真实浏览器编辑恢复仍待验收。
- 当前文档卡片优先显示已载入来源的商品及模块名称，保留原文件名，并区分「已建立来源，尚未保存精修版本」与已打开/保存隔离版本。选择器的待载入选项不会替代实际文档来源；未新增顶部工具栏。

## 用户验收

1. 先在 localhost:3000 登录同一账号，再刷新 localhost:3002。
2. 左栏「从商品模块载入」点击「读取电商商品」。
3. 选择真实商品及已出图模块，点击「基于当前模块图新建精修」。
4. 确认打开的是所选模块的当前图，左侧显示正确商品/模块来源。
5. 修改并点击「保存隔离版本」，刷新后打开此会话的版本，确认来源与编辑内容保留。
6. 回到正式电商工作台，确认当前商品预览、生成记录和版本指针没有变化。
7. 再次载入同一商品模块，确认出现已有版本提示；分别测试取消、继续编辑、新建。继续编辑后再次保存新增版本，新建从当前模块图片开始且旧会话保留；模块来源图片已变化时不提示旧图会话。
