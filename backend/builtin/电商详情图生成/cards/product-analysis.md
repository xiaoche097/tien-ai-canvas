# 商品事实与参考图职责

## 分析输出

| 字段 | 记录要求 |
| --- | --- |
| 商品身份 | 品类、SKU／款式；不同颜色或型号分开 |
| 可见外观 | 轮廓、比例、颜色、纹理、缝线、开口、扣件、图案及可见 Logo |
| 来源 | 每项事实标注来自哪张实拍或哪段用户资料 |
| 使用方式 | 只依据可见结构或用户明确描述；未知标待确认 |
| 适用人群 | 按商品与要求，不根据参考人物脸部推断买家族裔或年龄 |
| 待补资料 | 背面、安装接口、尺寸、成分、证书等不可见或无证据的部分 |
| 可表达卖点 | 事实 → 买家利益 → 可拍摄的证据画面；不虚构数据 |

若商品图仅有一个角度，只规划该图能支持的画面，不把生成的补角图升级成真实商品证据。资料冲突时展示冲突并确认，不靠视觉猜测制造商参数。

## 保真锁定

- 所有图共用同一组已确认商品事实；尺寸、结构、色号、配件数量、可见标识不得为了构图变化。
- 场景图允许改变环境、光线与合理摆放，不改变商品身份。材质特写必须来自可见细节，不发明组织纹理或内部剖面。
- 服饰保持领型、裙长、褶皱结构、图案与面料表现；包袋保持肩带、包型、开合、五金和实际承重关系；汽配以真实安装参考为准，不能把效果图当作车型适配证明。
- 禁止编造环保／医疗／安全认证、抗菌率、寿命、销量、评价、竞品缺陷、折扣与品牌授权。
- 用户文字事实可用于文案，但不能声称已通过图片或外部检验证实。
