# 详情图模块规划

## 方案结构

按用户数量规划，不强制塞满固定模板。未定数量可建议“1 张主视觉 + 4 张详情”，明确等待确认。模块可从以下选择并删去无证据内容：

| 模块 | 目标与证据 |
| --- | --- |
| 主视觉 | 清晰识别商品，展示完整轮廓及正确 SKU |
| 核心卖点 | 单张突出一个有依据的利益点 |
| 材质／工艺 | 用真实局部展示纹理、缝线或扣件 |
| 使用场景 | 合理环境与动作，商品尺度和接触自然 |
| 尺寸／规格 | 只有用户提供真实数值才标注；缺少则省略或补问 |
| 使用／安装 | 依真实步骤与结构，不编造安全承诺 |
| 对比／搭配 | 只用确认的同款规格、搭配或可证实差别 |

每张分别列出准确文案，短句优先。正文无法可靠渲染时建议减少文字或先出无字底图，说明仍需人工排版，不能承诺已生成可编辑文字层或 PSD。

## 平台与画幅

- 先按用户选择的平台和比例执行。详情图可建议 3:4、9:16、16:9、21:9，但实际受当前模型能力约束，不表示全部模型均支持。
- Amazon 第一张主图由用户选择 1:1 或 3:4；未选择时可推荐 1:1 等待确认，不强制固定。第一张白底、真实商品主体、不加额外营销文案、装饰标签或水印。后续附图可按确认的方案展示卖点和场景。
- Amazon A+／详情模块与第一张商品主图分开规划，不能将首图无文案规则误加到全部模块。
- 比例与选角是本项目创作配置，不冒充已核验的平台政策。需要确认当前上传规范时说明应核对站点和品类要求；没有检索工具不声称已查证。

## Amazon 项目选角偏好

延续本项目用户要求：需要人物时使用适合欧美市场、年龄与商品用途相符的模特，排除亚裔面孔。商品原图只定义商品，不默认复制原图人物脸部；纯商品图不添加人物。不能靠换肤色宣称完成选角，也不能承诺模型一定遵守；结果由用户核对。这是项目偏好，不是 Amazon 平台要求，不外推到其他平台。

## 系列与套版

沿用确认的品牌色、留白、标题层级、背景与摄影方向。用户给套版参考时仅迁移视觉语言，重新分析当前商品，不能沿用参考商品事实、文案或虚构其品牌授权。画布技能不自动访问原电商模板库，需用户提供参考图片或文字。
